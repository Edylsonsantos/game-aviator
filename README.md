# Aviator Game - Documentação

## Descrição
Este projeto implementa o jogo Aviator, um popular jogo de crash onde os jogadores apostam e tentam retirar seus ganhos antes que o avião "caia". O jogo foi desenvolvido com HTML, CSS (Tailwind) e JavaScript puro.

### Mecânica do Jogo
- **Multiplicador crescente**: O valor multiplicador aumenta progressivamente
- **Retirada antecipada**: O jogador pode retirar os ganhos a qualquer momento
- **Fim automático**: O jogo termina quando atinge um multiplicador aleatório pré-definido
- **Contagem regressiva**: Início automático após 7 segundos do término

### Interface
- **Histórico de apostas**: Mostra os últimos resultados
- **Controles de aposta**: Botões +/- e valores rápidos
- **Display do multiplicador**: Mostra o valor atual em tempo real
- **Feedback visual**: Animações do avião e mensagens de status

### Sistema Financeiro
- **Saldo do jogador**: Exibido no cabeçalho
- **Cálculo automático**: Ganhos e perdas são calculados e atualizados instantaneamente
- **Validação**: Impede apostas com saldo insuficiente

## Como Jogar

1. Insira o valor da aposta usando os botões +/- ou valores rápidos
2. Clique em "Apostar" para iniciar o jogo
3. Observe o multiplicador crescer
4. Clique em "Retirar" para garantir seus ganhos
5. O jogo termina automaticamente se o avião "cair"
6. Novo jogo inicia automaticamente após 7 segundos

## Estrutura do Código

- **HTML**: Estrutura da interface do jogo
